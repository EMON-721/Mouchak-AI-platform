## Real data collection/import priorities

1. Retrieve accessible and legally reusable source publications; retain exact publisher, date, URL and file hash.
2. If only human-accessible reports exist, allow Admin Curator to upload and manually verify an authorized copy.
3. Use `seed/` as clearly labelled ORIGINAL CURATED VOCABULARY + SYNTHETIC QA only; never claim those as published Bangladesh observation data.
4. Maintain per-row provenance; data published to users only after approval and quality checks.
5. Store consented user records privately and keep out of public official aggregate dashboards.
